# Source data setup

The complete source CSV is not committed to this repository. Download the UCI Bank Marketing dataset from the [UCI dataset page](https://archive.ics.uci.edu/dataset/222/bank), extract `bank-full.csv` from `bank.zip`, and save it here as `bank-full.csv`.

The dataset is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Cite: Moro, S., Rita, P., & Cortez, P. (2014), *Bank Marketing* [Dataset], UCI Machine Learning Repository, DOI: 10.24432/C5K306.
